
# PM2.5 Forecasting Across Indian Cities

## Overview

Air pollution is a major environmental and public-health concern in India, with **PM2.5** being one of the most important indicators of air quality.

This project focuses on the **statistical analysis and next-day forecasting of PM2.5 concentrations** across five major Indian cities. The analysis combines historical air-quality measurements with meteorological variables to investigate patterns in PM2.5 levels and develop forecasting models.

## Objectives

* Explore the temporal and statistical patterns of PM2.5 concentrations.
* Investigate the relationship between PM2.5 and meteorological variables.
* Compare air-pollution patterns across different Indian cities.
* Develop models for **next-day PM2.5 forecasting**.
* Evaluate and compare forecasting performance.

## Dataset

The project uses historical **air-quality and meteorological data** from five major Indian cities.

The dataset contains variables related to:

* PM2.5 concentration
* Meteorological conditions
* Date and time
* Other relevant air-quality measurements

The data were cleaned and prepared before conducting statistical analysis and forecasting.

## Methodology

The project follows the following workflow:

1. **Data Cleaning**

   * Handling missing observations
   * Preparing variables for analysis
   * Organizing observations chronologically

2. **Exploratory Data Analysis**

   * Examining distributions of PM2.5
   * Studying temporal patterns
   * Comparing pollution levels across cities
   * Investigating relationships between variables

3. **Statistical Analysis**

   * Descriptive statistics
   * Correlation analysis
   * Analysis of temporal and environmental patterns

4. **Forecasting**

   * Construction of next-day PM2.5 forecasting models
   * Model evaluation using appropriate performance metrics
   * Comparison of forecasting performance

## Results

The analysis provides insights into:

* Differences in PM2.5 levels across the selected cities.
* Temporal patterns and variation in air pollution.
* The relationship between meteorological conditions and PM2.5 concentrations.
* The effectiveness of statistical forecasting approaches for predicting next-day PM2.5 levels.

*Detailed results, visualizations, and model comparisons are available in the notebooks.*
